# Vishal Panuganti — Portfolio

A modern, responsive portfolio showcasing my work across **AI/ML, Data Science, Computer Vision, Data Engineering, and Analytics**.

Built with **Next.js, React, TypeScript, and Tailwind CSS**, the portfolio is designed to present my experience, technical skills, projects, and case studies in a clean and interactive format.

## ✨ Highlights

* Responsive, modern portfolio design
* Built with Next.js App Router
* Project case studies generated from structured project data
* Centralized portfolio content management
* Optimized for deployment on Vercel
* Type-safe development with TypeScript
* Tailwind CSS for responsive styling and UI
* Dedicated project pages for detailed case studies

## 🛠️ Tech Stack

* **Framework:** Next.js
* **Frontend:** React, TypeScript
* **Styling:** Tailwind CSS
* **Deployment:** Vercel
* **Package Manager:** npm

## 📁 Project Structure

Portfolio content is maintained centrally in:

```text
src/data/portfolio.ts
```

Project case studies and related sections are generated from the same structured data, making it easier to keep the portfolio consistent as projects and experience evolve.

## 🚀 Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

### Production Check

Before deploying, run:

```bash
npm run lint
npm run build
```

This helps ensure the project passes linting and builds successfully in a production environment.

## 📄 Resume

The portfolio includes a link to the downloadable resume.

Add the actual resume PDF at:

```text
public/resume/vishal-panuganti-resume.pdf
```

The portfolio is already configured to reference this path.

> The repository does not contain a fabricated or placeholder resume. The actual PDF should be added separately.

## ☁️ Deployment

The project is configured for **Vercel** and uses standard Next.js defaults.

To deploy:

1. Import the repository into Vercel.
2. Allow Vercel to detect the Next.js configuration automatically.
3. Deploy using the default build settings.
4. Connect a custom domain if required.

## 🎯 Purpose

This portfolio is more than a collection of projects. It is intended to provide a concise view of my experience building **data-driven and intelligent systems**, from data preparation and machine learning through deployment, analytics, and real-world applications.
